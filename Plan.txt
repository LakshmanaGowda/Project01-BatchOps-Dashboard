Phase 1 — Project Foundation (1 hour)
Goal

Create the application.

Features

The application will simulate a batch-monitoring dashboard.

The dashboard will display:

Feature	Description
Running jobs	Jobs currently executing
Successful jobs	Completed jobs
Failed jobs	Failed jobs
Server health	Healthy/Unhealthy
Application logs	Recent batch logs
